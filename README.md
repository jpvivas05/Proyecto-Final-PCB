# Proyecto-Final-PCB
Sistema de detección de frecuencia respiratoria basado en reflexión de luz infrarroja utilizando un ESP32, un fototransistor PT333-3C y una LED IR333-A. El sistema detecta variaciones de voltaje producidas por el movimiento de una membrana reflectiva y clasifica el ritmo respiratorio mediante indicadores LED en bajo, normal o alto ritmo.
Componentes utilizados
- ESP32 Dev Kit V1
- Fototransistor PT333-3C
- LED infrarroja IR333-A
- LM358P
- Resistencias:
- 220kΩ
- 33kΩ
- 220Ω
- Capacitor 220nF
- Capacitor 100nF
- LEDs indicadores:
  - Rojo
  - Verde
  - Azul
 
La PCB fue diseñada en Altium Designer siguiendo las especificaciones de manufactura para la máquina LPKF S103. El software fue diseñado para VSC con framework Arduino para ESP32.
